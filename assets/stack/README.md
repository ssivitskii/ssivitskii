# Stack artwork

Brand icon paths: [Simple Icons](https://github.com/simple-icons/simple-icons/tree/90646e4bf7f3b89df6c37e65baf3e7bc759a517c),
revision `90646e4bf7f3b89df6c37e65baf3e7bc759a517c`. Included icons: Python, NumPy, pandas, SciPy,
scikit-learn, PyTorch, Hugging Face, Plotly, FastAPI, Streamlit, PostgreSQL and Docker. Icon paths retain the source
geometry; colors are adapted for contrast in light and dark themes.

The upstream [CC0 license](SIMPLE-ICONS-LICENSE.md) is included. Brand names and
marks belong to their respective owners. The artwork identifies tools used in
the portfolio and does not imply endorsement.

The SVGs are self-contained, with no remote fonts or image requests.
